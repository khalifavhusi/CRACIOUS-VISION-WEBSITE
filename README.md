# Vision of Love — Charity System

GitHub Pages-ready version of the Vision of Love charity management website.

## Test it on GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. Open the GitHub Pages URL generated by GitHub.

## Important GitHub Pages storage limitation

The supplied functionality guide specifies a local backend that writes to
`TEXTFILE/*.txt`. GitHub Pages is a static hosting service and cannot execute
a Node.js backend or allow browser JavaScript to write files into the deployed
repository.

Therefore this GitHub Pages version uses **browser localStorage** for saved
records. This makes the website fully testable directly from GitHub Pages.
The Download buttons export the displayed records as CSV.

The four requested `TEXTFILE/*.txt` files are still included in the project
structure as required by the guide, but GitHub Pages cannot dynamically write
to them.

If actual live TXT-file writing is required, the same interface can be paired
with a separately hosted backend/API.
